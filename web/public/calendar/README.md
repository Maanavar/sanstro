# Calendar event images

Drop your deity/event illustration files here. The calendar legend, sidebar
date cards, and the Muhurtham Naal page hero will load them automatically.
If a file is missing the UI falls back to the emoji equivalent — so images
are optional and can be added at any time without code changes.

| File              | Used for             | Emoji fallback |
|-------------------|----------------------|----------------|
| `muhurtham.png`   | Tamil Muhurtham days | ✦              |
| `chathurthi.png`  | Chathurthi           | 🐘             |
| `sashti.png`      | Sashti               | 🦚             |
| `ekadashi.png`    | Ekadashi / Ekadhasi  | 🪷             |

Recommended: square PNG, transparent or white background, 256×256 or larger
(displayed at 16–56 px depending on context).
