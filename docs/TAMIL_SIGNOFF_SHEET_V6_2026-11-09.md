"உள்ளுக்குள்" stays, and the review agreed), A12 ("மறைக்காமல் … பேசி முடிக்க"), A16
("கலந்துகொள்ள"), A28, A30 (name moved before the verb), A33 ("பாடங்களில்"), A35 (first sentence).

**Where I adjusted the review's wording, and why:**

1. **A1, "உங்களிடம் இன்னொரு பக்கமும் இருக்கிறது."** Taken. Family readings use the same
   connecting sentence, so they get "அவரிடம் …". Otherwise a reading about Divya would say
   "you" to the relative. A new test checks this for all nine planets.
2. **A24.** The review's sentence repeated the line just before it ("இரு பக்க நியாயம்"), which
   is the repetition it was trying to remove. The new ending links the difficulty back to the
   strength, the same way A9 does: "காரணம், எதையும் தெளிவாக விளக்கத் தெரிந்தவருக்கு, அதன்
   எல்லாப் பக்கங்களும் அதே அளவு தெளிவாகத் தெரியும்."
3. **A35, Venus bhukti.** This sentence frame is shared by every bhukti, and it starts with "…வரை
   நடக்கும் சுக்கிர புக்தி". Pasting the review's sentence in would have said சுக்கிர புக்தி
   twice. It now reads "சுக்கிர புக்தி இந்தத் தசைக்குள் சில விஷயங்களைச் சற்று எளிதாக்கலாம்",
   which keeps the review's "சில விஷயங்கள் … சற்று எளிதாக" and its hedge.
4. **A36, "அங்கே சுக்கிரனின் பலம்".** Not "அங்கே அவருடைய பலம்". In a child's reading "அவர்"
   means the child everywhere else, so "அவருடைய பலம்" would read as Kavitha's strength. "அங்கே"
   still removes the repeated "அந்த இடத்தில்". A14 is unchanged, as the review asked.

**Astrology is still not covered by this sheet.** The hold list and Q10 are unchanged, in
`ASTROLOGER_QUESTIONS_2026-11-09.md`. A35's new wording is also subject to the astrologer.
