## 2. Is a Venus dasa always described as favourable?

The reading tells everyone in a Venus mahadasha:
"உறவுகளும் வசதிகளும் பணமும் எளிதாகக் கைகூடக்கூடிய காலம் இது."
The same sentence goes to every chart, whatever Venus's house, ownership or strength.
Should it change with Venus's condition in the chart? If so, which conditions matter most?

The same question applies to Guru bhukti, which the reading always describes as
"கல்வி, பிள்ளைகள், பெரியவர்களின் உதவி போன்றவை சாதகமாக அமையலாம்".

## 3. A child's "growth" topic: which house?

For a child, the reading's topic is "வளர்ச்சி" (growth: learning, calm, a steady home), and
it reads the **4th house** lord. For example: "Kavitha-வின் நான்காம் வீட்டின் அதிபதி சுக்கிரன்…"
Is the 4th house right for this? Or should learning be read from the 5th house, or from both?
