# தசகம் → பத்தாண்டு: drafts for the Tamil reviewer (23 Oct 2026)

**For the Tamil reviewer.** In §10 you said தசகம் should be பத்தாண்டு. We held the 40-odd inflected uses
for one reason: they sit near the timing detector's number-word rule. That question is now settled (below),
so here is every use with a draft. **Nothing below is on any page yet.** Each draft goes in only after you tick
it or correct it.

## What changes

The drafts are mechanical: the stem changes and the case ending stays.

| Now | Draft |
|---|---|
| தசகங்கள், தசகங்களில், தசகங்களின், தசகங்களாக, தசகங்களுக்கு … | பத்தாண்டுகள், பத்தாண்டுகளில், பத்தாண்டுகளின், பத்தாண்டுகளாக, பத்தாண்டுகளுக்கு … |
| தசகத்திலும் | பத்தாண்டிலும் |
| பல-தசக (before a noun) | பல பத்தாண்டு |

**Please check especially:** sandhi after the new word (பத்தாண்டுகளாகத் / -க் / -ப் carry over unchanged,
but பல பத்தாண்டு before a noun may want a doubled consonant); whether பத்தாண்டு reads as "a decade of
life" rather than "a ten-year term" in each sentence; and whether some sentences read better recast
without the word at all (for example முதல் பத்தாண்டுகள் → இளமைக் காலம்).

## The timing rule (settled for engineering)

The rule that dasa prose carries no timing bans digits, spelled spans (பத்து ஆண்டுகள், இருபது மாதங்கள்)
and decade-of-age words (நாற்பதுகள்). The English pages say "decades" freely ("the network built across
the earlier decades"), and the detector allows it, because it names a span of life, not a length.
பத்தாண்டு is the same word, so it is allowed the same way. பத்து ஆண்டுகள் is still banned. Both cases
are pinned in `web/lib/natchathiram-dasa-prose.test.ts`.
